# Pasos para instalar

- Clone el proyecto desde la terminal en la ruta de los proyectos de android studio(StudioProjects) : git clone git@github.com:steven55sol/Taller4-programacion.git
- Abra el pryecto en android studio
- Instale los paquetes y librerias desde la consola con: **flutter pub get**
- y ahora si ya puede emular la aplicacion
